title: Quickstart
description: Install Envil and choose the correct environment creation boundary.
---

```bash
bun add @ayronforge/envil effect
```

## Synchronous applications

Use `createEnvSync` only when every value comes from the runtime environment.

```ts
import { createEnvSync, port, redacted, url } from "@ayronforge/envil";

export const env = createEnvSync({
  server: {
    DATABASE_URL: redacted(url),
    PORT: port,
  },
  client: {
    APP_URL: url,
  },
  prefix: {
    client: "VITE_",
  },
});
```

`createEnvSync` rejects `resolvers` at typecheck.

## Effect applications

`createEnv` is the primary API and always returns an Effect, even without
resolvers.

```ts
import { Effect } from "effect";
import { createEnv, requiredString } from "@ayronforge/envil";

const program = createEnv({
  server: { API_TOKEN: requiredString },
});

const env = Effect.runSync(program);
```

## Promise applications

```ts
import { createEnvPromise, requiredString } from "@ayronforge/envil";

const env = await createEnvPromise({
  server: { API_TOKEN: requiredString },
});
```

When an adapter leaves an Effect service unprovided, `createEnvPromise` requires
the corresponding Layer as its second argument.
