---
title: Envil
description: Type-safe environment validation with explicit exposure and secret boundaries.
---

Envil turns environment configuration into one typed startup boundary.

The model has four parts:

1. Schemas decode runtime strings into application values.
2. Buckets define where each value may be exposed.
3. Resolver adapters supply authoritative server secrets.
4. A type-only contract describes the safe structure for inference and tooling.

```ts
import { createEnvSync, redacted, url } from "@ayronforge/envil";

export const env = createEnvSync({
  server: {
    DATABASE_URL: redacted(url),
  },
  client: {
    APP_URL: url,
  },
  prefix: {
    client: "VITE_",
  },
});
```

`server` never reaches browser code. `client` and `shared` may, so Envil rejects
redacted schemas and resolver keys outside `server` at typecheck and runtime.

Envil never places secret values, remote references, defaults, credentials, SDK
responses, or raw provider errors in its type contract.
