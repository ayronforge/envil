---
title: GCP Secret Manager
description: Resolve server secrets with the isolated GCP adapter.
---

```bash
bun add @google-cloud/secret-manager
```

```ts
import { createEnv, requiredString } from "@ayronforge/envil";
import { gcpSecretsAdapter } from "@ayronforge/envil/gcp";

export const env = createEnv({
  server: {
    STRIPE_SECRET_KEY: requiredString,
  },
  resolvers: ({ resolve }) => [
    resolve(gcpSecretsAdapter, {
      projectId: "my-project",
      version: "latest",
      secrets: {
        STRIPE_SECRET_KEY: "stripe-secret-key",
      },
    }),
  ],
});
```

Fully qualified resource names do not require `projectId`. GCP gRPC not-found
code `5` becomes `Option.none()`; other failures remain
`ResolverRequestFailed`. Payload bytes are decoded as UTF-8.
