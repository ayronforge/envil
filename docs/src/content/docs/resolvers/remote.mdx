---
title: Custom SecretSource
description: Implement a custom secret provider as an Effect Service.
---

`customSecretsAdapter` is backed by the `SecretSource` Effect Service.

```ts
import { Effect, Option } from "effect";
import {
  SecretSource,
  createEnv,
  customSecretsAdapter,
  requiredString,
} from "@ayronforge/envil";

const CustomSecretSourceLive = SecretSource.fromPromise({
  get: async (reference) => {
    const value = await vault.get(reference);
    return value === undefined ? Option.none() : Option.some(value);
  },
});

const program = createEnv({
  server: {
    INTERNAL_TOKEN: requiredString,
  },
  resolvers: ({ resolve }) => [
    resolve(customSecretsAdapter, {
      secrets: {
        INTERNAL_TOKEN: "tenant/internal-token",
      },
    }),
  ],
}).pipe(Effect.provide(CustomSecretSourceLive));
```

`fromPromise` requires `Option` explicitly. Present strings are redacted
immediately, absence stays `Option.none()`, and Promise rejection becomes a
sanitized `SecretSourceRequestFailed`.

Implement `SecretSource` directly with another secret-safe `SecretSourceError`
when you need more granular typed errors.
