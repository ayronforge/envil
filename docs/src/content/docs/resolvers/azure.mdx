---
title: Azure Key Vault
description: Resolve server secrets with the isolated Azure adapter.
---

```bash
bun add @azure/keyvault-secrets @azure/identity
```

```ts
import { createEnv, requiredString } from "@ayronforge/envil";
import { azureKeyVaultAdapter } from "@ayronforge/envil/azure";

export const env = createEnv({
  server: {
    DATABASE_PASSWORD: requiredString,
  },
  resolvers: ({ resolve }) => [
    resolve(azureKeyVaultAdapter, {
      vaultUrl: "https://my-vault.vault.azure.net",
      secrets: {
        DATABASE_PASSWORD: "database-password",
      },
    }),
  ],
});
```

The optional `credential` field uses Azure's official `TokenCredential` type.
Without it, the adapter creates `DefaultAzureCredential`. HTTP 404 becomes
`Option.none()`; other SDK failures stay typed errors.
