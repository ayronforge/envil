---
title: 1Password
description: Resolve server secrets with the isolated 1Password adapter.
---

```bash
bun add @1password/sdk
```

```ts
import { createEnv, requiredString } from "@ayronforge/envil";
import { onePasswordSecretsAdapter } from "@ayronforge/envil/1password";

export const env = createEnv({
  server: {
    DATABASE_PASSWORD: requiredString,
  },
  resolvers: ({ resolve }) => [
    resolve(onePasswordSecretsAdapter, {
      secrets: {
        DATABASE_PASSWORD: "op://vault/item/password",
      },
    }),
  ],
});
```

Pass `serviceAccountToken` or set `OP_SERVICE_ACCOUNT_TOKEN`. The adapter uses
the SDK's `resolveAll` batch response. Any unresolved individual response makes
the batch fail closed; it is never converted into partial success.
