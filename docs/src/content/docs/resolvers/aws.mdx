---
title: AWS Secrets Manager
description: Resolve server secrets with the isolated AWS adapter.
---

Install the optional peer:

```bash
bun add @aws-sdk/client-secrets-manager
```

```ts
import { createEnv, requiredString } from "@ayronforge/envil";
import { awsSecretsAdapter } from "@ayronforge/envil/aws";

export const env = createEnv({
  server: {
    DATABASE_PASSWORD: requiredString,
  },
  resolvers: ({ resolve }) => [
    resolve(awsSecretsAdapter, {
      region: "us-east-1",
      secrets: {
        DATABASE_PASSWORD: "production/database#password",
      },
    }),
  ],
});
```

The `#field` suffix safely extracts a JSON object field. Malformed JSON becomes
`ResolverResponseDecodeFailed` without retaining the value or reference.

AWS batch requests preserve provider batching. Reliable
`ResourceNotFoundException` responses become `Option.none()`; partial or
operational batch failures remain errors.
