---
title: Effect and Results
description: Handle Envil failures through Effect or the asResult operator.
---

`createEnv` exposes expected failures in Effect's typed error channel.

```ts
const program = createEnv(options).pipe(
  Effect.tapError((error) => reportSafeError(error)),
  Effect.catchTag("EnvValidationError", recoverValidation),
);
```

Use `asResult()` when a boundary needs a discriminated value:

```ts
import { Effect } from "effect";
import { asResult, createEnv } from "@ayronforge/envil";

const result = await createEnv(options).pipe(
  asResult(),
  Effect.runPromise,
);

if (result.success) {
  result.data;
} else {
  result.error;
}
```

The result shape is:

```ts
type Result<A, E> =
  | { readonly success: true; readonly data: A }
  | { readonly success: false; readonly error: E };
```

`asResult()` converts only typed failures. Defects and interruptions remain
defects and interruptions.

With a custom Layer, provide it before `asResult()` when Layer construction
errors must also become result failures:

```ts
createEnv(options).pipe(
  Effect.provide(CustomSecretSourceLive),
  asResult(),
);
```
