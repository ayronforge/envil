## Validation issues

`EnvValidationError.issues` is a frozen discriminated union:

```ts
type EnvValidationIssue =
  | {
      readonly _tag: "MissingVariable";
      readonly key: string;
      readonly schemaIdentifier?: string;
      readonly sensitive: boolean;
    }
  | {
      readonly _tag: "InvalidVariable";
      readonly key: string;
      readonly schemaIdentifier?: string;
      readonly sensitive: boolean;
    };
```

Rejected values are never retained. Messages include only physical keys, safe
schema identifiers, and fixed text.

## Resolver failures

Adapters return discriminable errors:

- `ResolverConfigurationError`
- `ResolverInitializationError`
- `ResolverRequestFailed`
- `ResolverResponseDecodeFailed`
- `SecretSourceRequestFailed`

Errors do not retain secret values, remote references, tenant IDs, response
bodies, provider DTOs, or original SDK exceptions.

Absence is not an error. Adapters return `Option.none()` only for a reliable
provider-specific not-found signal. Operational failures stay in the error
channel.
