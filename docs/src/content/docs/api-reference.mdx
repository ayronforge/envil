## Creation

### createEnv

Always returns:

```ts
Effect.Effect<Env, EnvError, Requirements>
```

The optional `resolvers` field uses `({ resolve }) => [...]`.

### createEnvSync

Returns the immutable environment and rejects `resolvers` at typecheck.
Validation failures are thrown at the synchronous boundary.

### createEnvPromise

Returns `Promise<Env>`. A second `{ layer }` argument is required only when
resolver requirements remain unprovided.

## Inference

```ts
InferEnv<T>
```

It returns the complete decoded environment type and works with an Effect,
sync value, Promise, or awaited value.

## Results

```ts
asResult()
Result<A, E>
```

`asResult()` converts only the typed Effect error channel.

## Resolver protocol

```ts
ResolverAdapter<Name, Reference, Options, Error, Requirements>
```

Built-in values:

```ts
awsSecretsAdapter
gcpSecretsAdapter
azureKeyVaultAdapter
onePasswordSecretsAdapter
customSecretsAdapter
```

## Custom source

```ts
SecretSource
SecretSource.fromPromise({ get })
SecretSourceError
SecretSourceRequestFailed
```

`get` returns:

```ts
Effect.Effect<
  Option.Option<Redacted<string>>,
  SecretSourceRequestFailed
>
```
